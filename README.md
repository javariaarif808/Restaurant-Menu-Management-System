# Restaurant Menu Management System

A console-based Restaurant Menu Management System developed in C++ using Object-Oriented Programming (OOP) concepts.

## About the Project

This project was developed as a group project as part of our university coursework. It demonstrates the use of Object-Oriented Programming concepts to create and manage a restaurant menu.

## OOP Concepts Used

- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Constructors
- Virtual Functions
- Access Specifiers

## Features

- Display restaurant menu items
- Manage different food items
- Use inheritance for different types of food
- Demonstrate polymorphism through overridden functions
- Display food item prices

- C++
